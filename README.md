# IP 位址檢測工具

🌐 IP Address Checker - 檢測您的 IPv4/IPv6 位址與地理位置資訊

## 🌐 網站網址
https://lance70176.github.io/ip-checker/

## ✨ 功能特色

- 🌍 **IPv4/IPv6 檢測** - 顯示您的公網 IP 位址
- 📍 **地理位置** - 顯示 ISP、城市、區域、國家
- 🗺️ **地圖顯示** - 使用 OpenStreetMap 標記您的位置
- 🔒 **安全提醒** - 提醒您位置資訊可能暴露
- 📱 **響應式設計** - 支援手機與桌機瀏覽

## 🚀 使用方法

1. 開啟網站即可自動檢測
2. 查看您的 IP 位址與地理位置
3. 在地圖上查看大致位置

## 🛡️ 隱私說明

- 純前端檢測，所有資料由瀏覽器直接向 ipapi.co 請求
- 不會儲存或傳送您的 IP 資訊到第三方伺服器
- 地圖僅顯示 ISP 的大致位置，非精確 GPS 定位

## 🛠️ 技術棧

- HTML5
- CSS3 (Backdrop Filter 毛玻璃效果)
- JavaScript (Fetch API)
- Leaflet.js (地圖)
- ipapi.co (IP 資訊 API)
- GitHub Pages
